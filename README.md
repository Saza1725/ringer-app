# Ringer-App – Web-Version

Training, Übungen und Ernährung fürs Ringen. Installierbare Web-App, läuft offline.
Alle Einträge bleiben auf dem jeweiligen Gerät.

**Installieren**
- iPhone: Link in Safari öffnen → Teilen → „Zum Home-Bildschirm“
- Android: Link in Chrome öffnen → Menü → „App installieren“
